    # Code Quality Skill

## Overview

Use this skill for repository validation: style alignment, script hygiene, documentation completeness, and lightweight verification.

## Capabilities

- review changes for consistency with nearby patterns
- identify missing docs/tests/validation steps
- validate shell-script hygiene
- validate workflow/rules documents for completeness

## Usage Examples

```text
User: Verify the new workflow docs are complete.
Action: run validation checks and summarize gaps or success.
```
