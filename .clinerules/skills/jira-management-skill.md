# Jira Management Skill

## Overview

Use this skill for Jira ticket lookup, analysis, comments, updates, and subtask management.

## Capabilities

- read Jira issue details and acceptance criteria
- search issues by assignee/status/project
- create or update subtasks
- add implementation/testing summaries back to Jira

## Usage Examples

```text
User: Analyze Jira JCS-15253.
Action: read the issue, summarize requirements, and turn them into actionable tasks.
```
