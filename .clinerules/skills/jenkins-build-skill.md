# Jenkins Build Skill

## Overview

Use this skill for Jenkins job discovery, triggering, and build-status checks in WLS OCI workflows.

## Capabilities

- inspect Jenkins job definitions
- trigger jobs with default or explicit parameters
- check queue/build status
- retrieve logs and results for troubleshooting

## Usage Examples

```text
User: Trigger the dev_upload_team_pink_image_oci job.
Action: verify the job exists, trigger it, then check queue/build status.
```
