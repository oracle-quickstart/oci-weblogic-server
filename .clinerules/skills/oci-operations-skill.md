# OCI Operations Skill

## Overview

Use this skill for OCI-related automation in the repository: secrets, image operations, and OCI CLI usage.

## Capabilities

- inspect OCI CLI-based automation flows
- retrieve and reason about OCI secret payloads
- support image build/publish workflows
- validate OCI-related script parameters

## Usage Examples

```text
User: Extract access_token from an OCI secret payload.
Action: parse the JSON and use the derived token safely.
```
